## 🏗️ Tech Stack

**No framework, no bundler, no runtime dependencies.** Every page is static HTML
generated at build time and served as-is.

| Layer | Technology |
|---|---|
| **Markup** | 15 static HTML pages, generated by `tools/build-site.mjs` |
| **Styling** | One hand-written stylesheet, CSS custom properties, no preprocessor |
| **Scripting** | Native ES modules, zero libraries, all progressive enhancement |
| **Motion** | Native View Transitions API, IntersectionObserver, CSS animations |
| **Fonts** | Anton, Inter, JetBrains Mono, Silkscreen — self-hosted, latin subset |
| **Images** | `sharp` pipeline → AVIF + WebP at 320/480/960/native, plus LQIP |
| **Deployment** | Vercel (CI/CD via GitHub) |

There are no external requests of any kind at runtime — no CDN, no font host,
no analytics.

### Build

```bash
npm install
npm run images   # regenerate the responsive ladder + manifest (needs sharp)
npm run fonts    # copy woff2 out of node_modules
npm run site     # regenerate all 15 pages + sitemap.xml + robots.txt
npm run assets   # all three
npm run serve    # http://localhost:8000
```

The HTML files in the repo are **generated artifacts**. Editing them by hand
works until the next `npm run site` overwrites them. The real sources are:

| File | Holds |
|---|---|
| `tools/lib/content.mjs` | Every word on the site, the gel taxonomy, the layout sequences, the lighting cue sheet |
| `tools/lib/shell.mjs` | `<head>`, nav, HUD, rig, footer, JSON-LD |
| `tools/lib/media.mjs` | `<picture>` construction and the `sizes` table |
| `css/style.css` | All styling, with a numbered table of contents in the header |
| `js/*.js` | One module per concern, each initialised in isolation |

## 🎛️ The design system — "the chrome is a machine, the photographs are the signal"

The interface is built as the lighting rig these photographs were shot under.
A projection layer drifts behind every page in the same six hues that run
through the work; scrolling into a section is a lighting cue that fades the
gel, ticks the channel readout on the HUD, and puts one RGB-split hit on the
heading.

**One rule governs all of it: no effect ever distorts a photograph.** Glitch,
scanlines, pixelation and stepped (`steps()`) easing live in the chrome only.
Where that rule collides with a feature, the feature gives way — prev/next
navigation between two frame pages deliberately skips the view-transition morph,
because the two photographs have different aspect ratios and the transition
pseudo-elements would stretch one into the other's shape.

| Token | Value | Usage |
|---|---|---|
| `--ui` | `#c084fc` | Systematic UI accent — eyebrows, indices, focus rings (7.95:1) |
| `--mag` | `#ff10f0` | Display type and accents only (6.58:1) |
| `--amb` | `#ffb020` | Warm accent, sampled from the stage light he shoots in |
| `--ink-0` | `#000000` | Ground |
| `--text-1` / `--text-2` / `--text-3` | `#f4f4f5` / `#a1a1aa` / `#83838d` | Body copy scale |
| `--gel` | angle | Per-section hue rotation of the projection layer |

Contrast is measured, not guessed, and the numbers are recorded in the token
block. Never layer two accents on each other — magenta on amber is 1.13:1.

### v4 — "Afterglow"

Same palette, now lit. One additive stylesheet section (`§29`, delete it to get v3 back) plus `js/glow.js`:
neon-tube magenta type that flickers on as its section arrives, a pink pool under the hero headline,
lamps and a neon rule on every section head, outlined display numerals on the service/process cells with a
pointer-following spotlight, alternating solid/outline ticker, sheen + bloom buttons, framed hover lift,
glass nav with an active-link tube, and a cropped gradient wordmark closing the footer. Scanlines were thinned
so the white display type reads solid. Every glow sits on the ground, never over a photograph, and all of
it is off under `prefers-reduced-motion`.

**Psychedelia (§30).** The violet UI accent is now a phase, not a colour: one registered angle (`--psy`)
turns the wheel every 24s and rebuilds `--ui` in OKLCH at fixed lightness, so every label, index, edge and
focus ring flows through the spectrum while holding ~10:1 on black. Ticker separators and nav indices are
phase-offset so colour travels across them, the rainbow buttons and spectrum name scroll, and the projection
layer drifts round the wheel. Magenta stays fixed as the brand anchor. Stepped to 5 updates/s to keep the
whole-page restyle cheap; held at the original violet under reduced motion.

## 🚀 Pipeline Workflow

This project was built using the **Preciado Tech Web Pipeline** — a repeatable 5-phase process:

```
1. DISCOVERY  →  Scrape client assets (images, text, social links)
2. SCAFFOLD   →  Initialize project, deploy preview to Vercel
3. ENHANCE    →  Claude Code (Sonnet 4.6) implements features
4. POLISH     →  UX debug pass, accessibility audit, performance optimization
5. DELIVER    →  Final deploy, build documentation video, client handoff
```

### What was built (6 enhancement passes)

| Pass | Feature | Details |
|---|---|---|
| 1 | **Lightbox** | Fullscreen image viewer with keyboard nav, touch swipe, focus trap |
| 2 | **Featured Capture** | Editorial poster module with neon pink accents |
| 3 | **SEO + OG** | Meta tags, Open Graph, Twitter Card, JSON-LD Person schema |
| 4 | **Accessibility** | Skip-link, ARIA labels, focus indicators, reduced motion |
| 5 | **Performance** | Critical CSS, preconnect, deferred scripts, lazy loading |
| 6 | **UX Debug** | 11 bugs fixed — mobile menu, scroll, nav links, hero fallback |
| 7 | **Instagram Feed** | Attempted and since removed. The 12-post pull was rate-limited at build time and the section shipped as a "Follow" CTA; the v2 rebuild dropped it rather than keep a placeholder in the markup |

### v2 — nomad-cyberpunk rebuild

Replaced the Tailwind/GSAP scaffold with the static generator, self-hosted
fonts, the `sharp` image ladder, and per-photograph pages at `/work/<slug>/`.

### v3 — "Light Rig"

| Area | What changed |
|---|---|
| **Atmosphere** | The projection layer: a 1.2 KB raster upscaled by the compositor, drifting behind every page, hue-rotating per section from a cue sheet in `content.mjs` |
| **Borders** | HUD becomes a truss — measured ticks, channel readout, scroll-driven level meter. Frame brackets draw in on reveal |
| **Navigation** | Cross-document View Transitions: a grid frame morphs into its own page and back |
| **Lightbox** | Native `<dialog>`, keyboard + swipe, clones the grid's own `<picture>` so no second image ladder ships |
| **Archive** | Filter by light signature — CSS-only at its core, animated re-layout and URL state added by script |
| **Intro** | Projector warm-up → focus pull → signal lock → shutter. Home page only, once per session |
| **Hire path** | Services and Process sections — real disciplines, no invented rates or testimonials |
| **Housekeeping** | `sitemap.xml` + `robots.txt`, reference-counted scroll lock, live capability queries, `.sr-only` (referenced but never defined), `--text-3` raised for contrast under the wash |

## ♿ Accessibility & progressive enhancement

The site is fully usable with JavaScript disabled: every photograph is real
markup, the contact form posts natively, and the archive filter — built on a
radio group, `:has()` and `[data-light~=…]` — genuinely still filters. Script
adds the animated re-layout and URL state on top of a filter that already works.

`prefers-reduced-motion` removes movement, never content: no drift, no glitch,
no intro, no parallax, and no view-transition snapshot is ever taken. The
lightbox still opens, still walks the set, still swipes.
